# 신호 이름 사전과 별칭 증명 사전등록

판정 기록을 열기 전에 작성하고 해시를 고정한다.

## 1. 범위
- 대상: 록히드마틴 61개 항목, 생성 문장의 LTL(ltl_pt, ltl_ft) 입력 전처리.
- 사전과 별칭은 이번 실험의 입력 전처리이다. 동결 판정 도구 v1.2.0(code_tree_sha256 1fda2c19...)은 변경하지 않는다.
- RQ1 내지 RQ4의 정의는 유지한다. 전처리 결과는 기존 T1(앵커), T2, skeleton 결과와 같은 분모로 나란히 보고한다.

## 3. S1 사전 구성 규칙
- 한 항목 안에서 생성 이름 하나는 기준 신호 하나에 대응한다. 대응이 없는 이름은 그대로 둔다. 신뢰도 H(이름이 사실상 같음)와 M(의미상 같다고 판단)을 기록한다.
- 구성자는 저자 쪽 에이전트이고 기준 FRETish를 보고 작성했다. 판정 결과는 구성 시점에 쌍 단위로 보지 않았다.
- 초안 407쌍을 전수 재검토해 41쌍을 제거했다(타입 검사 불일치 18, 타입 검사 혼합 중 제거 10, 모호한 이름 3, 신호가 아닌 한계 상수 10). 제거 목록은 map/removed.json.
- 미대응 이름 999개를 항목별로 재검토해 26쌍을 추가했다(map/rules_08.txt).

## 4. S2 적용 규칙 (apply_dict.py)
- 식별자 토큰을 문장이 속한 항목의 사전으로 동시에 바꾼다. 여는 괄호가 바로 따라오는 토큰(함수 이름)은 바꾸지 않는다.
- 충돌 규칙: 한 문장 안에서 치환 결과가 같은 문장의 다른 이름과 같아지거나 서로 다른 두 이름이 같은 기준 신호가 되면 해당 치환을 하지 않는다(38건).
- 여러 항목에 나오는 문장은 항목별 결과가 같아야 한다.
- 결과: 2730개 문장 중 1642개의 LTL이 바뀐다. 생성 변수 이름의 기준 일치율 22.3%에서 54.5%, 문장 전체 일치율 6.3%에서 33.3%.

## 5. S3 별칭 증명 규칙 (alias_apply.py)
정리: 선형 실수 산술 아래에서 g <-> r이 항상 참이면, 식 φ에서 부분식 g를 r로 바꾼 φ'는 모든 실행 기록에서 φ와 같은 값을 갖는다. 근거: LTL의 의미는 시점별 원자의 값 위에서 정의되고, 같은 값을 갖는 부분식의 치환은 식 구조에 대한 귀납으로 전체 값을 보존한다.

절차:
1. 생성 식(ltl_pt와 ltl_ft 각각)에서 시간 연산자가 없는 최대 부분식 g를 찾는다.
2. 같은 항목 기준 식의 시간 연산자 없는 부분식 r 중 변수 집합이 g와 같은 것을 후보로 한다.
3. 동결 도구의 원자 추상화 아래에서 g와 r이 이미 명제적으로 동치이면 건너뛴다.
4. z3로 not (g <-> r)이 unsat이면 g를 r로 바꾼다. 제한 시간 10000 ms, 결과가 unsat이 아니면 바꾸지 않는다.
5. 변경마다 (item, sentence, gen, ref) 증명서를 alias/alias_certificates.jsonl에 기록한다.

적용 조건:
- 변수 타입은 사용 위치(조건식 안은 불리언, 산술 안은 실수)로 정한다. 타입이 충돌하면 대상에서 뺀다.
- pre로 시작하는 함수와 FTP 변수를 포함한 부분식은 대상에서 뺀다.
- 분모가 상수가 아닌 나눗셈을 포함한 부분식은 대상에서 뺀다.
- 변수 이름은 S2 이후의 이름으로 비교한다.
- 여러 항목에 나오는 문장은 항목별 결과가 같을 때만 적용한다.

결과: 140개 문장, 증명서 302건, 7개 항목. 증명서 302건 전부를 증명기와 독립인 숫자 대입 검사(cert_check.py, 건당 3000점)로 확인했고 불일치는 0건이다.

## 6. 판정 설정
동결 도구 v1.2.0, `--mode anchor`, `--cap 128`, `--timeout 120`, NuSMV 엔진, `--allow-unfrozen` 사용 안 함. 분모 규칙은 기존과 같고 파서 거부, UND, N/M, 문장 없음은 분모에 남긴다.

## 7. 대조
1. 음성 대조: control/units_control.json(300 단위, 339 쌍, 항목을 31칸 밀어 다른 항목 기준과 비교). S3 출력을 쓴다. 기대: SAME 0.
2. 이름 교환 대조: 본 판정에서 SAME인 쌍 중 변수가 둘 이상인 쌍에서 두 변수를 맞바꾼 식을 같은 기준과 판정한다(swap_control.py). 기대: SAME 아님. 두 변수에 대해 대칭인 식에서 남는 SAME은 따로 세어 손으로 확인한다.
3. 별칭 대조: 증명서가 있는 문장의 S2 출력과 S3 출력을 같은 기준과 판정해 역할 이동표를 만든다.
