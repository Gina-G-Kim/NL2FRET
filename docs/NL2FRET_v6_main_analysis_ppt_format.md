## 5. 동치 (z3 사후 판정, 추가 절)

방법: 생성 문장의 과거시제 LTL과 기준 문장 LTL을 z3로 길이 8까지 비교(같은 이름 비교, 안 되면 변수 단사 대응 후 비교). 판정 대상 2025문장(vf 큐).

전체 분포(문장 사용 횟수 기준): no_renaming_equivalent 1054, unsupported 426, alignment_required 304, equivalent_under_renaming 210, equivalent_bounded 24, equivalent_under_swap_renaming 5(동치로 세지 않음), generated_stronger 2.

중요한 제한
- 동치가 한 번이라도 나온 항목은 61개 중 15개(03_REG 10, 02_TUSTIN 2, 00_TRIPLEX 1, 05_NN 1, 07_AP 1; invariant 7, timed 5, conditional 3)뿐입니다. 아래 표는 이 15개 항목만 대상으로 하므로 절대 수치는 높게 나오는 선택 편향이 있고, 방식 사이 상대 비교로만 읽어야 합니다.
- no_renaming_equivalent는 "어떤 대응으로도 동치가 아님"이지만, 원자 명제 분할이 다른 경우(같은 의미를 다르게 쪼갠 경우)도 섞여 있어 모두 의미가 틀렸다는 뜻은 아닙니다. 얼마나 섞였는지는 알 수 없습니다.
- 반복 3회 풀링이 아니라 문장 사용 횟수 기준입니다.

## 6. 요약

1. 구문과 realizability: +R이 압도적으로 낮은 실패율(10.2% 대 DIRECT 29.0%). 자유 변환은 DIRECT, PARA와 구분되지 않음.
2. 일관성: +R만 오름(골격 80.7%). 자유 변환과 +V는 오르지 않음.
3. 의미(동치와 타이밍): 템플릿 효과 없음, +R은 timed 유형의 타이밍만 개선, invariant에서는 오히려 타이밍 일치 저하. +V는 방향 긍정, 통계적 확정 불가.
4. 정보 보존: +R이 숫자를 가장 많이 빠뜨림(자연어 숫자의 43.0%).
