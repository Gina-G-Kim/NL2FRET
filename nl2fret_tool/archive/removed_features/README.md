# Removed features (2026-11-17)

Second removal of the same day (experiment 027, request of the project owner: remove what is not needed): the hash list of the tool code and its check. The first removal (J+def) is described below.

Moved here, not deleted, when the tool was tidied up to the original design (`docs/V20_BATCH_DESIGN.md` sections 0 and 9; `experiments/025_tool_v20_install/notes/CHANGES.md`, entry of 2026-11-17).
